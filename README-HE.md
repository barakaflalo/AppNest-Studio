# אולפן AppNest — גרסת GitHub Pages

זו אפליקציית דפדפן. אין צורך בהתקנה במחשב, בהפעלת שרת מקומי, ב-Python או ב-Node.js. קובצי ההפעלה המקומית הושמטו מחבילה זו.

## עדכון האתר הקיים

1. חלצו את קובץ ה-ZIP.
2. העלו את כל הקבצים שחולצו לתיקייה שממנה אתר GitHub Pages הקיים של האפליקציה מתפרסם. קובץ index.html צריך להחליף את index.html הקיים באותה תיקייה. אין להעלות רק את ה-ZIP או רק את index.html: נדרשים גם כל קובצי studio-*.js ו-studio-editor.css.
3. שמרו את השינויים ב-GitHub והמתינו להשלמת פרסום Pages. אין צורך לשנות את הגדרות הפרסום של אתר שכבר עובד.
4. פתחו את כתובת האתר הרגילה. אם מוצג עדיין העורך הישן, סגרו את הלשוניות של האתר ופתחו מחדש לאחר העדכון. אין צורך לנקות נתוני אתר, כדי לשמור על ההקלטות המקומיות.

הקבצים משתמשים בנתיבים יחסיים ומתאימים גם לאתר שמתפרסם תחת שם המאגר, למשל https://username.github.io/repository/. חבילה זו הוכנה להעלאה; היא לא פורסמה אוטומטית בחשבון GitHub שלכם.

## היכן מתבצעת העבודה

GitHub Pages מגיש לדפדפן את קובצי האפליקציה. העריכה, החיבורים, העבודה עם שירה וליווי נפרדים וייצוא השמע נעשים בדפדפן במחשב. הפרויקטים וההקלטות נשמרים באחסון המקומי של הדפדפן ובקבצים שתבחרו לשמור. העלאת קוד האפליקציה ל-GitHub אינה מעלה את השירים שלכם ל-GitHub.

מנועי ההמרה/היצירה של Sing4Me שנכתבו ב-Python הם רכיב נפרד ואינם כלולים בגרסה זו. GitHub Pages אינו מפעיל Python או מודלי GPU בשרת; הוספתם בעתיד תדרוש שירות עיבוד נפרד או מימוש המתאים לדפדפן.

## מה השתנה בעורך

- אפשר לבחור ולערוך כל קטע, להגדיל את גל הקול, להזיז את התצוגה ולכוון גבולות בדיוק של אלפיות שנייה.
- גזירה, מחיקה, פיצול, שינוי סדר, ביטול וביצוע מחדש שומרים את חומרי המקור כחלק מהפרויקט.
- בין קטעים אפשר לקבוע חפיפה ועקומת מעבר, ולהאזין במיוחד לאזור החיבור.
- לכל קטע יש עוצמה וכניסה/יציאה הדרגתיות. אפשר להתאים רמות יחסיות ולהפחית עוצמה כאשר פסגות הדגימות חורגות מהסף. אלה כלי עזר לעריכה; אין כאן מאסטרינג אוטומטי או מדידת true peak.
- אפשר להחליף מילה או משפט בקטע קיים מאותה הקלטה או מהקלטה אחרת.
- אפשר לייבא ליווי נפרד, לערוך את השירה מעליו ולייצא את התוצאה ל־WAV או ל־MP3.

## חיבור שני קטעים

1. ייבאו קובץ והוסיפו את הקטע הבא.
2. ברשימת הקטעים בחרו את הקטע השני. הגדירו חפיפה עם הקטע שלפניו.
3. נסו מעבר ליניארי לחומרים דומים; מעבר equal power יכול להתאים לחומרים שונים. האזינו ובדקו שהעוצמה אינה קופצת או נחלשת.
4. השתמשו בהאזנה למעבר ובכוונון הגבולות. לחיבור מוזיקלי חשוב להתאים גם את המקום במשפט המוזיקלי ואת המקצב, ולא רק להעלים קליק.

העורך אינו מבצע בשלב זה התאמת קצב או סולם אוטומטית. חיבור חלק תלוי גם בחומרי המקור ובבחירת נקודות החיתוך.

## החלפת מילה מתוך הקלטה קיימת

1. מצאו ביצוע חלופי של המילה או המשפט: באותו שיר או בהקלטה אחרת של אותו זמר. רצוי להשאיר מעט חומר לפני המילה ואחריה.
2. סמנו את הקטע הרצוי ובחרו **שמור כמקטע החלפה**, או טענו מקור חלופי באזור ההחלפה.
3. בחרו את קטע היעד וסמנו בו את המילה שרוצים להחליף. האזינו בנפרד ליעד ולמקור החלופי.
4. לשמירת התזמון נדרשים אורכי בחירה שווים. כפתור התאמת האורך מזיז את גבול הבחירה במקור; הוא **אינו מותח את האודיו** ואינו משנה את המנגינה.
5. קבעו מעבר קצר בגבולות, בצעו את ההחלפה והאזינו לשני החיבורים. ניתן לבטל ולנסות גבולות אחרים. במצב שינוי אורך, האודיו שלאחר ההחלפה זז בהתאם.

ביצוע מאותו זמר מקל על ההתאמה, אך עדיין צריך להתאים גובה צליל, נשימה, עוצמה, הגייה והדהוד. לפעמים החלפת משפט קצר נשמעת טבעית יותר מהחלפת מילה בודדת.

אם עובדים על שיר מלא שכבר עורבב, ההחלפה מחליפה גם את הליווי שבקטע. עבודה עם ערוץ שירה נפרד וליווי נפרד נותנת שליטה טובה יותר. עבור Suno, השתמשו באפשרות ייצוא הערוצים הזמינה בחשבון ובשיר שלכם. העורך אינו מפריד שירה מליווי בעצמו, אינו משכפל קול ואינו הופך זמר אחד לזמר אחר.

## שמירה וגיבוי

**שמרו קובץ פרויקט ‎.appnest לפני סיום העבודה ובנקודות חשובות.** הקובץ כולל את הגדרות העריכה ואת מקורות האודיו הדרושים, ומאפשר לפתוח את הפרויקט להמשך עבודה. שמירת WAV או MP3 יוצרת תוצאה שטוחה לשמיעה ולשיתוף; היא אינה מחליפה קובץ פרויקט.

השמירה המקומית בדפדפן היא עזר להתאוששות. היא שייכת לדפדפן, לפרופיל ולכתובת המדויקת, כולל מספר היציאה. מעבר לכתובת אתר אחרת, לשרת מקומי או לדפדפן אחר עשוי להציג אחסון נפרד. במקרה כזה פתחו את קובץ ה־‎.appnest ששמרתם. ניקוי נתוני אתר, מצב פרטי או מגבלות נפח עלולים למחוק או למנוע שמירה מקומית.

גיבוי ההגדרות שבמסך ההגדרות אינו תחליף לגיבוי הפרויקט. מחיקת ספריית ההקלטות אינה מוחקת קובצי פרויקט שכבר הורדתם למחשב. פרויקטים ארוכים וקובצי WAV דורשים זיכרון ונפח פנוי; מומלץ לשמור עותקים של חומרי המקור.

## עיבוד מקומי ושירותים חיצוניים

העריכה, החיבור, ההחלפה והייצוא מתבצעים בדפדפן. קידוד MP3 והמרות מתקדמות עשויים להוריד ספריות מ־CDN, ולכן נדרש חיבור לאינטרנט כדי לטעון אותן. GitHub Pages משמש להגשת קובצי האתר; עיבוד העריכה נשאר בדפדפן.

סנכרון מילים בעזרת בינה הוא שירות אופציונלי: הפעלתו שולחת את קובץ השמע לספק שבחרתם. העוזר האופציונלי שולח לספק את השיחה ואת הקשר האפליקציה. השירותים תלויים במפתח, בתנאי הספק ובזמינותו. פרטים נוספים בקובץ **privacy_policy.html** ובמסך ההגדרות.

האזינו למעברים באוזניות וגם ברמקולים, השוו למקור, ובדקו את הקובץ שיוצא. העורך מספק שליטה טובה יותר בחיבור ובהחלפה; אי אפשר להבטיח שכל מילה מכל הקלטה תשתלב בלי זכר לעריכה.
